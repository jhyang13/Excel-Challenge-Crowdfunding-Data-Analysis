# Crowdfunding Campaign Analysis

## Overview

This project explores trends and success patterns in crowdfunding campaigns using a dataset of over 1,000 projects collected from online crowdfunding platforms such as Kickstarter and Indiegogo.

The objective of this analysis is to identify factors that may influence campaign success by examining funding goals, campaign categories, launch timing, and supporter behavior. The project combines data cleaning, statistical analysis, pivot-table reporting, and data visualization techniques using Microsoft Excel.

# Project Goals

The main goals of this project are to:

- Analyze crowdfunding campaign outcomes
- Identify patterns associated with successful projects
- Explore relationships between funding goals and campaign performance
- Evaluate supporter engagement through backer statistics
- Visualize trends using charts and pivot tables
- Practice data analysis and reporting workflows using Excel

# Dataset

The dataset contains information from 1,000 crowdfunding campaigns, including:

- Campaign category and sub-category
- Funding goal amounts
- Amount pledged
- Campaign outcomes
- Number of backers
- Launch and deadline timestamps
- Country information

The dataset was used for educational and analytical purposes.

# Analysis & Features

## Data Cleaning & Transformation

Performed data preprocessing tasks including:

- Converting Unix timestamps into readable dates
- Splitting category and sub-category fields
- Calculating:
  - Percentage funded
  - Average donation per backer

## Campaign Outcome Analysis

Built pivot tables and visualizations to analyze campaign performance across:

- Categories
- Sub-categories
- Countries
- Launch dates

Created:

- Stacked column charts
- Line charts
- Pivot-table dashboards

## Goal-Based Funding Analysis

Analyzed how funding goals impact campaign outcomes by grouping projects into different goal ranges and comparing:

- Success rates
- Failure rates
- Cancellation rates

Used statistical summaries and line charts to identify trends between funding targets and campaign performance.

## Statistical Analysis

Compared successful and unsuccessful campaigns using backer statistics, including:

- Mean
- Median
- Minimum / Maximum
- Variance
- Standard deviation

This analysis helped evaluate supporter behavior and variability between campaign outcomes.

# Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Statistical Functions
- Data Visualization Techniques

# Key Insights

Some major findings from this project include:

- Campaigns with moderate funding goals tended to perform better than extremely high-goal campaigns.
- Certain categories consistently showed higher success rates.
- Successful campaigns generally attracted significantly more backers and higher average donations.
- Launch timing and category selection appeared to influence campaign performance.
